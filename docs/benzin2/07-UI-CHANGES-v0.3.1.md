# تغییرات رابط کاربری — نسخهٔ ۰٫۳٫۱

این سند همان شش درخواست آخر مالک محصول است و می‌گوید هر کدام کجای کد نشسته و چرا این‌طور
پیاده شده است. هیچ‌کدام از این تغییرات نصب‌کنندهٔ جدید لازم ندارد: از کانال محتوا می‌آید
(`content-latest`، حدود ۱ مگابایت).

## ۱) استان و شهرستان به‌جای یک «شهر»

- داده: `packages/shared/src/geo.ts` — **۳۱ استان** و **۴۸۴ شهرستان** (تقسیمات کشوری رسمی
  مرکز آمار). داخل `@benzin/shared` است، پس اپ بدون هیچ درخواست شبکه‌ای آبشار استان → شهرستان
  را می‌سازد و آفلاین هم کار می‌کند.
- مدل: هر سفارش `province` و `county` دارد (به‌همراه `zoneId` قبلی که برای سازگاری مانده).
  API جفت استان/شهرستان را با `isValidPlace` اعتبارسنجی می‌کند؛ جفت ناموجود → `VALIDATION_ERROR`.
- فیلتر بازار: `province` و `county` روی `/v1/orders` و `/v1/stats/market` (هر دو اختیاری).
  «همهٔ ایران» یعنی هر دو خالی.

## ۲) خرید سبز، فروش قرمز

- `apps/web/src/lib/order-view.ts`: `tone` برای خرید `brand` (سبز) و برای فروش `danger` (قرمز).
- دکمهٔ نوع آگهی در بازار و در فرم ثبت سفارش، حاشیهٔ کارت‌ها، برچسب نوع آگهی و چیپ‌ها همین
  زبان رنگی را دارند. قبلاً هر دو سبز بودند.

## ۳) هزینهٔ پمپ (۱۵۰۰ / ۳۰۰۰ / ۱۰۰۰۰) فقط ورودی فروشنده

- در فرم ثبت سفارش، انتخاب پایهٔ پمپ **فقط وقتی نوع آگهی «فروش» است** دیده می‌شود
  (`CreateOrderPage`). در درخواست خرید پنهان است و سمت API صفر حساب می‌شود.
- `OrderView` سه فیلد تازه دارد: `pumpFeeToman`، `buyerRateToman` و `buyerTotalToman`.
  خریدار در کارت بازار «۳٬۴۵۰ تومان هر لیتر» را می‌بیند و زیرش «سهمیه ۴۵۰ + پمپ ۳٬۰۰۰».
- فرم ثبت سفارش هم پیش از ارسال، همان جمع را زنده نشان می‌دهد تا فروشنده بداند خریدار چه
  عددی می‌بیند. فیلتر پایه در بازار حذف شد؛ پایه دیگر چیزی نیست که خریدار آن را انتخاب کند.

## ۴) حذف تب «جستجو»

- `BottomNav` حالا چهار مقصد دارد: بازار، سفارش، سفارش‌های من، پروفایل.
- مسیر `/search` به‌عنوان alias روی همان بازار نگه داشته شد تا لینک‌های قبلی نشکنند.

## ۵) آمار قیمت همان شهر

`GET /v1/stats/market?province=…&county=…&side=…` (بدون `tier`؛ همهٔ پایه‌ها با هم):

| عدد                        | معنی                                                       |
| -------------------------- | ---------------------------------------------------------- |
| `averageTotalRateToman`    | میانگین «قیمت هر لیتر با هزینهٔ پمپ» در آن شهرستان          |
| `minTotalRateToman`        | کمترین                                                     |
| `maxTotalRateToman`        | بیشترین                                                    |
| `buyLitres` / `sellLitres` | چند لیتر درخواست خرید و چند لیتر آگهی فروش در آنجا باز است |
| `buyCount` / `sellCount`   | تعداد سفارش‌های هر طرف                                     |
| `byTier`                   | همان میانگین به تفکیک پایهٔ پمپ (۱۵۰۰ / ۳۰۰۰ / ۱۰٬۰۰۰)      |

قیمت‌های پرت (کمتر از درصدِ تنظیم‌شده از میانهٔ همان شهر) از میانگین کنار گذاشته و شمرده
می‌شوند (`excludedSuspicious`). قبلاً معیار پرت بودن، نرخ رسمی پایه بود که با مدل جدید
(پمپ به‌عنوان ورودی فروشنده) بی‌معنی شده بود.

## ۶) میانگین کشوری برای مقایسه

- `nationalAverageTotalRateToman` = همان متریک، روی کل کشور (همان سمت، همهٔ پایه‌ها).
- `nationalCountyCount` = چند شهرستان در بازهٔ آماری معامله داشته‌اند.
- کارت مقایسه در بازار: «میانگین کشوری: ۵٬۲۳۶ تومان در ۴ شهرستان» و در کنارش
  «۱۴۷ تومان گران‌تر از کشور» (سبز/قرمز).

## دادهٔ نمایشی

برای این‌که این صفحه‌ها در اجرای تازه خالی نباشند، بیلد محلی ۱۲ آگهی نمونه در چهار شهرستان
