# G-10 — نرخ پاسخ‌دهی و رتبه

**پذیرش:** `response_rate = پاسخ‌داده‌شده / رزروهای دریافتی` در ۳۰ روز گذشته؛ نشان در کارت آگهی؛
مرتب‌سازی `price_per_liter ASC` سپس `response_rate DESC`؛ سه بی‌پاسخی پیاپی → حذف موقت ۲۴ ساعته از
فهرست + قابل بازبینی در پنل. **هیچ امتیاز منفی‌ای به کاربر داده نشود.**

این سند می‌گوید عدد از کجا می‌آید، چرا «بی‌پاسخی» جریمه نیست، و پشتیبانی چطور آن را بازبینی می‌کند.

## ۱) عدد از کجا می‌آید

- **دریافتی (`received`)** = رزروهایی که در ۳۰ روز گذشته روی آگهی‌های این فروشنده ثبت شده‌اند.
  تنها استثنا: رزروی که **خریدار** پیش از هر تصمیمی لغو کرده — این یکی به دفتر فروشنده نرسیده و
  پای او نوشته نمی‌شود.
- **پاسخ‌داده‌شده (`answered`)** = همان رزروها اگر فروشنده تصمیم گرفته باشد؛ «تأیید» و **«رد»** هر دو
  پاسخ‌اند. فقط سکوت پاسخ نیست.
- نرخ = `answered / received` با یک رقم اعشار، ذخیره‌شده به‌صورت `response_rate_permille` (۰…۱۰۰۰)
  تا مرتب‌سازی در SQL یک مقایسهٔ صحیح بماند.
- شمارنده‌ها روی خود کاربر نگه داشته می‌شوند (مهاجرت `0009`) و در سه جا تازه می‌شوند:
  هر بار فروشنده پاسخ می‌دهد، هر بار درخواستش بی‌پاسخ می‌میرد، و یک چرخهٔ روزانهٔ زمان‌بند برای
  پنجره‌هایی که فقط کهنه شده‌اند (بدون رویداد تازه).

## ۲) «هیچ امتیاز منفی» یعنی چه

نرخ پاسخ‌دهی به دفتر اعتبار (`reputation_events`) **دست نمی‌زند**. سه بی‌پاسخی پیاپی هیچ رویدادی
ایجاد نمی‌کند، هیچ عددی را کم نمی‌کند و حساب را معلق نمی‌کند. تنها پیامدش این است:

> آگهی‌های همان فروشنده تا ۲۴ ساعت در بازار دیده نمی‌شوند.

و همین هم موقتی است: زمان‌بند در هر چرخه قفل‌های سررسیده را برمی‌دارد
(`ownerResponse.liftDuePauses`)، آدیت `owner.relisted` ثبت می‌کند و به فروشنده اعلان
«آگهی‌های شما به بازار برگشت» می‌فرستد. در تست، امتیاز و تاریخچهٔ اعتبار قبل و بعد از سه بی‌پاسخی
بایت‌به‌بایت یکی است.

آگهی در حالت توقف فقط از **بازار** حذف می‌شود؛ «سفارش‌های من» و صفحهٔ معامله دست‌نخورده کار می‌کنند
و رزروهای فعال هم باطل نمی‌شوند.

## ۳) قرارداد API

```
GET /v1/me/response                       (نیازمند ورود)
→ { ownerId, ratePercent: 92.3|null, answered, received,
    labelFa: "۹۲٫۳٪ پاسخ‌دهی", unansweredStreak, delistedUntil }

GET /v1/orders?side=SELL&sort=price       (هر کارت)
→ items[].owner = { id, ratePercent, labelFa, answered, received }

GET /v1/admin/listing-pauses              (فقط ADMIN/OWNER)
→ { items: [ { …user, until, reasonFa } ], total }

POST /v1/admin/users/:id/relist           (فقط ADMIN/OWNER)
→ AdminUserRow   ·   409 NOT_DELISTED اگر فروشنده در توقف نبود
```

`labelFa` روی سرور ساخته می‌شود تا اپ هیچ‌وقت خودش عدد را گرد نکند:

| وضعیت | متن نشان |
|---|---|
| هنوز درخواستی نیامده | «تازه‌کار» |
| ۱ یا ۲ درخواست | «کم‌سابقه» (نمونهٔ کوچک، عدد ادعا نمی‌کنیم) |
| ۳ درخواست و بیشتر | «۹۲٫۳٪ پاسخ‌دهی» |

## ۴) مرتب‌سازی بازار

`sort=price` حالا `price_per_liter ASC` و بعد `response_rate_permille DESC` است؛ فروشنده‌ای که نرخ
ندارد (`NULL`) آخر می‌آید. در Postgres این از `LEFT JOIN users o_owner` و ستون پروجکشن خوانده می‌شود؛
در آداپتور حافظه، نرخ هر مالک یک بار برای هر جستجو خوانده می‌شود، نه یک بار برای هر مقایسه.

مالکان در حالت توقف در **همان کوئری** فیلتر می‌شوند (`o.owner_id <> ALL($n)`)، پیش از صفحه‌بندی؛
پس صفحه هیچ‌وقت «کم» برنمی‌گردد و `total` درست است.

## ۵) داده و مهاجرت

`infra/migrations/0009_response_rate.sql` روی `users`:

| ستون | معنی |
|---|---|
| `response_answered` | درخواست‌هایی که فروشنده تصمیم گرفت (هر دو جهت) |
| `response_received` | درخواست‌هایی که به میز فروشنده رسید |
| `response_rate_permille` | ۰…۱۰۰۰ برای مرتب‌سازی؛ `NULL` تا اولین درخواست |
| `response_refreshed_at` | آخرین بازمحاسبهٔ پنجره |
| `unanswered_streak` | بی‌پاسخی‌های پیاپی |
| `delisted_until` | پایان توقف نمایش (حداکثر ۲۴ ساعت) |

دو ایندکس: یکی جزئی روی `delisted_until IS NOT NULL` (چون در هر کوئری بازار چک می‌شود) و یکی روی
`response_refreshed_at` (برای چرخهٔ روزانه). بک‌فیل لازم نیست: کاربرهای قدیمی `received = 0` دارند و
نشان «تازه‌کار» می‌گیرند تا وقتی درخواست تازه‌ای برسد.

## ۶) اپ‌ها

- **بازار:** نشان روی هر کارت (`data-testid="owner-response"`)، با رنگ برند برای نرخ ۸۰٪ و بالاتر.
- **پروفایل:** کارت «نرخ پاسخ‌دهی» با درصد، شمارش `answered/received`، هشدار بی‌پاسخی پیاپی، و اگر
  آگهی‌ها متوقف باشند تاریخ پایان توقف؛ زیرش یک خط: «بی‌پاسخی هیچ امتیازی از تو کم نمی‌کند.»
- **پنل:** ستون «نرخ پاسخ‌دهی» و «خارج از فهرست» در فهرست کاربران، و کارت «فروشندگان خارج از فهرست»
  با دلیل، زمان پایان و دکمهٔ «بازگرداندن به بازار».
